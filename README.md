# Lady Elka — Cloud preview

Public repository containing only the generated static website and a dependency-free copy build.

Timeweb Cloud App Platform: frontend / static website, branch `main`, build command `npm run build`, output directory `dist`.

Payment is disabled (`payment: null`). Product HTML comes from the saved catalog snapshot dated 2026-10-01, whose price freshness is unconfirmed. Browser catalog feeds use the existing public Supabase endpoints. This preview does not establish production checkout readiness.

Use the Timeweb test domain first. The existing main domain and backend are not switched by this repository.
